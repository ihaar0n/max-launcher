# MAX Launcher

Launcher de escritorio para Fortnite hecho por **ax¡d**.

- Abre Fortnite con tus cuentas de Epic sin escribir la contraseña y cambia de cuenta en un clic.
- Tienda de objetos del día, alertas de pavos y Salvar el Mundo.
- Amigos, grupo, perfiles de gráficos y limpieza de Fortnite.
- Avisos y novedades desde MAX Panel, y actualizaciones automáticas.

## Descargar

Descarga el instalador `MAX Setup x.y.z.exe` desde [Releases](https://github.com/ihaar0n/max-launcher/releases). El launcher se actualiza solo cuando sale una versión nueva.

## Desarrollo

```bash
npm install
npm start          # abrir el launcher
npm run crear      # crear el instalador en /instalador
```

Para publicar una versión nueva: `PUBLICAR-UPDATE.bat` (pide un token de GitHub con permiso `repo`).
